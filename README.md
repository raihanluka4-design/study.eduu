# Study Companion - Academic Catch-Up & Virtual Lab Portal

## Core Objectives
1. **Teacher Upload Portal**: Notes (PDF/Text/Docs), Lecture Recordings/Video lessons, Lab experiment guides, Assignment tracking.
2. **Absent Student Catch-Up Portal**: Filter missed classes by date/subject, instant catch-up progress tracking, lesson playback, and downloadable resources.
3. **Virtual Lab & Practicals Hub**: Interactive virtual science experiments (e.g., Acid-Base Titration, Ohm's Law Circuit, Simple Pendulum), lab manuals, observation tables with auto-calculation, and safety guidelines.
4. **Academic Workload Optimizer**: Smart homework & study scheduler, deadline stress/load heatmaps, priority task organizer.

## Tech Stack
- **HTML5 & Vanilla CSS3**: Modern glassmorphic modern UI, responsive layout, custom CSS design system, typography (Outfit & Inter), smooth micro-interactions.
- **Modern Vanilla JavaScript (ES6+)**: IndexedDB + LocalStorage for persistent file storage (documents, video links/files, notes, lab practicals data), state management, simulation physics/canvas rendering.
